Project Overview & Architecture

About Scholarship Eligibility Portal

An educational decision-support platform designed to eliminate financial aid barriers by providing transparent, multi-criteria scholarship discovery.

🎯

1. Project Purpose & Academic Objectives

Across India, hundreds of government and philanthropic scholarship schemes remain unutilized simply because students find official guidelines fragmented, convoluted, or overwhelming. Students frequently miss deadlines or waste effort applying for schemes for which they do not meet critical cutoff criteria.

The Scholarship Eligibility Portal resolves this challenge by creating a single, centralized web application where students can enter their academic credentials and immediately receive a transparent evaluation of which state, national, or private schemes they satisfy.

Centralized Discovery Aggregates central, state (e.g. Telangana ePASS), and foundation scholarships in one responsive interface.
Rule-by-Rule Transparency Explains exactly why a student qualifies or fails each condition (marks, income, state, quota).
Strict Data Privacy Never collects Aadhaar numbers, bank account details, or passwords, ensuring complete student privacy.
Safe Official Routing Directs students directly to verified official government portals (NSP, AICTE, ePASS) with no intermediary fees.

2. How the Eligibility Checker Engine Works

Unlike simplistic keyword search engines, our Express.js backend features a dedicated evaluation service (eligibility.service.js) that performs multi-criteria relational validation for every scholarship record:

Rule 1
Education Level & Course Compatibility

Compares student enrollment (e.g. Undergraduate, Diploma, Intermediate) against the scheme's permissible education tiers and courses.

Rule 2
Academic Percentage Cutoff

Compares the student's previous examination percentage against the minimum threshold (e.g. 80% for NSP Merit, 50% for ePASS). Marks within 3% of cutoffs are classified as "May Be Eligible" to account for reservation relaxations.

Rule 3
Family Income Ceiling Verification

Checks student family income against the scheme's maximum income ceiling (e.g. ≤ ₹2,00,000 for ePASS, ≤ ₹8,00,000 for AICTE Pragati, or no limit for open merit).

Rule 4
Domicile / State Reservation

Validates if the scheme accepts "All India" applicants or requires local state domicile (e.g., Telangana residence).

Rule 5
Social Category & Special Quotas

Matches reservations (SC, ST, OBC, EWS, Minority), female-specific STEM grants (AICTE Pragati), and disability support (≥ 40% certified disability).

Evaluation Status Definitions:

  • Meets Listed Criteria All configured rules pass without conflict.
  • May Be Eligible Score or status is borderline, or requires institutional verification.
  • Not Eligible Under Listed Rules One or more mandatory requirements (income, marks, or domicile) are violated.

3. Technologies & Architecture

The application is constructed using a decoupled full-stack architecture with clear separation of concerns between frontend presentation and backend business logic:

Layer Technology Role & Implementation Details
Frontend Framework Angular (TypeScript) Standalone components, Angular Router for SPA navigation, Reactive Forms / Two-way data binding.
HTTP Client Angular HttpClient Asynchronous REST API consumption using RxJS Observables, error handling and loading indicators.
UI & Styling HTML5 & Custom CSS3 Responsive grid, CSS variables, mobile-first design, color-coded status badges, custom SVG icons.
Backend Server Node.js & Express.js RESTful API routing, JSON body parsing, CORS middleware, input sanitization and error handlers.
Business Logic Eligibility Service (JS) Modular multi-rule evaluation engine that ranks and explains scholarship matches.
Data Storage JSON Database Structured scholarships.json database storing realistic and verified national/state schemes.
Client Storage Browser LocalStorage Persistent client-side storage for bookmarked scholarships without requiring user accounts or logins.

4. Academic Demonstration Disclaimer

This software application has been developed purely as a College Academic Project for educational demonstration in software engineering, full-stack web development, and algorithms.

The eligibility results generated by this website are preliminary simulations intended to assist students in discovering opportunities. The portal does not guarantee receipt of any scholarship, does not disburse funds, and does not replace official government verification. The final award decision is strictly subject to official scrutiny by the designated authorities (National Scholarship Portal, Government of Telangana, AICTE, or private trusts).
